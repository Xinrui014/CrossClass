## 标注规则（每个物体一个 rectangle，用相同的字符串连接）

| 物体 | label 写法 | 例子 |
|---|---|---|
| component（有印 label） | 写它的 designator | `R16` |
| component（没有印 label） | `?` + class | `?capacitor`，`?ignore`（test point / mech / fuse） |
| 文字框 | `#` + 印的字 | `#R16` |
| OCR 读到但不在 BOM 里的字 | `#?` + OCR 字符串 | `#?R1G`：改对，或者删掉 |

- **link 不用另外标**：component `R16` 和文字框 `#R16` 的字符串相同，就算连在一起，我之后自动连接。
- **class 不用标**：有 designator 的 component，class 自动从 BOM 来。只有没印 label 的 component 才需要在 `?` 后面写 class。
- 这和你说的"先标 text，再用 text 作为 component 的 label"是同一个思路。
- 预标已经填好：Card6_T 有 117 个 component、140 个文字框。你主要做的是改错的、删多的、补漏的。

## 关于把厂商设计文件作为训练数据：我觉得很值得做

**它能补的东西**：我们现在的训练数据全部是 KiCad（约 2.4 万块板子），主要是开源和爱好者的设计。厂商 eval board 和 WACV、21PCB 的测试板是同一类：工业设计软件（Allegro、PADS、Altium），密度更高，silkscreen 的习惯也不同。所以它们更接近测试 domain。

**能拿到什么、拿不到什么**：

| 信息 | 能拿到吗 |
|---|---|
| part 位置、designator、side、footprint | 能。来自 placement / XY 文件、IPC-356、ASCII layout |
| part 的 class | 能，来自 BOM |
| **silkscreen 上 designator 文字的位置**（训练 linker 必须要） | **难**。二进制的 Allegro / PADS 文件不能直接读。Gerber 的 silkscreen 层是画出来的线条，不是字符串。解决办法：把 silkscreen Gerber 渲染成干净的图片，再用 OCR 读，读干净的渲染图很准。PADS ASCII 和 Altium ASCII 可以直接读出文字位置 |

**规模和获取方式**：
- **TI**：几百块 EVM 有设计文件。**不用登录**，L40 可以直接下载（subagent 已经验证过）。最容易开始。
- **ADI**：几百个 CN reference design 加上几千块 eval board，但是需要登录，而且网站拦截脚本访问。只能手动下载，或者先少量试。
- 需要注意版权：这些文件一般允许用于研究，但不能再发布。我们只用来训练，不公开原文件。

**公平性**：21PCB 和 WACV 里的板子一定要从训练数据里排除，按板子型号去重。最好再检查同一系列的板子（例如同一个 CN 编号的不同接口版本 SDPZ / ARDZ）。
