1. 三个结果（42 张测试图，5,585 个标注元件）：① 检测器 baseline mAP50 0.541，错类 420；② 检测器定位 + VLM 判类别（双格图：3 倍近景 + 周围环境）0.450，错类 1,045；③ 检测器定位 + OCR 关联 0.570，错类 371。漏检 1,520 个（27 %）三者相同，因为 ②③ 只改类别、不加框。
  2. 给 VLM 更大的视野有帮助，但没改变结论。旧版只给 160 px 原图的小裁图时 ② 是 0.400、错类 1,201；加上周围环境后 0.450、错类 1,045（单看类别准确率 70.6 % → 73.4 %），仍比检测器差。
  3. ② 现在错在哪：电容判成电阻 463 次、判成电感 205 次（电容错类 678，占它所有错误的 65 %）；二极管错 114（判成电阻 55、电感 32）；连接器错 89（排针判成开关 35）。0402 电容的棕色/米色封装，Qwen 一直当成电阻。
  4. ② 比检测器好的类别变多了：电阻 104 → 73 错、电感 51 → 20、开关 27 → 10、三极管 40 → 15、晶振 14 → 9；IC 持平（38 → 37）。也就是说，看得到周围环境后，除了电容、二极管、连接器，其余类别 VLM 都比检测器准。
  5. ③ 仍是最好的：每个类别都不比检测器差，错类 371。剩下的错：电阻 → 电容 80、二极管 → 电容 28、电感 → 电容 27、三极管 → IC 26——多数是标签没印、或标签被邻居的框抢走（关联错）。
  6. 含义：类别这件事上，"读板上印的字"仍比"看图猜"可靠；VLM 看图的问题集中在电容这一类，其余类别它已经不差。再往上要靠减少漏检（小元件、连接器）和补上检测器没见过的外观。
