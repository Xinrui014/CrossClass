WACV Label Review

WACV 标注里可能有问题的地方，共 … 个候选。每张截图回答一个问题：接受 = 是，按建议修改；拒绝 = 不是，保持原标注；看不清 = 照片上判断不了，也保持原标注。你的选择会自动保存，可以分几次做完。

  • A同一个编号标在了多个框上，板上只印了一次。问：这些框是同一个元件吗？接受 → 评分时把它们当作一个元件。
  • B元件的编号板上没印，旁边却有一个只差一个字符的 label。问：这个元件就是板上印的那个编号吗？接受 → 改成板上印的编号。
  • C元件在标注里没有编号，旁边有一个没被使用、类型相符的 label。问：这个 label 是它的吗？接受 → 给它补上这个编号。
A：同编号的多个框 B / C：要判断的元件 相关的 label 细框：其他元件和文字

键盘：J / K 或 ↓ / ↑ 切换卡片，A 接受，R 拒绝，U 看不清。选完自动跳到下一个未处理的。
