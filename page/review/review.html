WACV Label Review

WACV 标注里有 … 处元件和丝印编号（label）对不上，大多是 label 被分给了错误的元件。每个候选里有 1–3 个元件：请在整板照片上给每个元件点出它真正的 label：点那个文字框（只是选中），再按 Enter 或「确定」保存。板上没印编号按 N，看不清按 U。选择会自动保存，可以分几次做完。

  • A几个框标了同一个编号，板上只印了一次。两种情况：① 这几个框其实是同一个元件（比如一个排针上插了两个跳线帽）→ 按 S；② 是不同的元件 → 给每个元件点出它真正的 label。
  • B元件编号和旁边一个文字框差一个字符：WACV 标注里有一边读错了（比如照片上印 C124，文字框却写成 C134）。看照片，点「文字框读错了」或「元件编号错了」。
  • C元件在标注里没有编号。黄色虚线是旁边一个没被使用的 label。
  • M你审核时发现、我手动加进来的问题（比如漏了文字框的 FPGA）。卡片上写着要做什么。
现在要找 label 的元件 同一候选里的其他元件 建议的 label 你选的 label（有连线） 没被任何元件使用的 label 标注里已属于别的元件的 label 你已选给别的元件的 label 你标为「不是元件编号」的文字

板上印了编号，但没有文字框（比如 "JTAG P1" 的 P1）：按 T 或点「画文字框」，在照片上拖一个框把那个编号框住，填上文字，按 Enter。新框是绿色的，会连到当前元件。

漏了元件，或者元件框不对：按 P（画元件框）拖一个新框，选类别，再点它的 label 文字框（没印就点「没印」），按 Enter。按 E（改元件框）给当前元件重新拖一个框，按 Enter 替换（原来的框留作灰色虚线）。

有的字不是元件编号（引脚名 P1.30、GND、3.3V、TX、功能说明……）：Shift + 点这个文字框，把它标为「不是元件编号」（再点一次取消；手机上先按工具栏的「标记非编号文字」再点）。元件旁边只有这种字的话，按 N（没印 label）。

整板视图：点文字框 = 选中，Enter / 确定 = 保存，Esc = 取消；每次保存后都可以「撤销」，或按 Ctrl+Z；滚轮 / 双指缩放，拖动平移；鼠标停在框上会显示它的文字。S 把当前元件和还没选答案的框合并成一个元件（A 类；已经选好的框不动），R 删除这个元件框（框住的不是元件，比如整块洞洞板），Shift + 点 / X 标记非编号文字，N 没印，U 看不清，Del 清除，Tab 换元件，J / K 下一个 / 上一个候选，B 切换框，D 设计编号（有设计文件的板子），F 整板，H 回到目标，Esc 关闭。保存后停在原地，按 J 去下一个。

黄点 + 黄字：设计文件里的元件编号和位置 要看的元件 标注里给它的 label 设计编号对应的 label（板上印了的话）
  • 标错标注的编号和设计文件不一样，而且设计文件的元件就在这个框上。
  • 漏连标注没给编号，但板上印了设计编号的 label。
  • 不确定不一样，但设计文件的元件离这个框较远（常常是设计文件和照片的板子版本不同）。
  • 没印编号设计文件有编号，但板上没有印这个编号（标注留空是对的）。
