## Findings
- **Noise boxes** (vias, silkscreen print, non-component pads from the KiCad file, target none, `--noise 0.5/1.0`): KiCad val with
  noise added stays 97.6 % (untrained model 90.5 %, 12.6 % of noise boxes linked); WACV e2e link acc 52 -> 75 %; clean41 unchanged.
  The KiCad build dropped every non-label box, which was the domain gap — not the photos.
- **Output format matters**: one class per box (ultralytics default) vs top-3 hypotheses: +0.06 mAP50 for every method, the detector
  included. Report both. Box score = box score x P(class); a fixed score after a class change hurts (mult_or fix +0.017, 1 class).
- **Soft cascade C** removes hard decisions; most of its gain is soft reading. C with real OCR = perfect OCR under the prefix table,
  so reading is no longer the bottleneck; the text -> class mapping (board naming: LEDs named L1-L7, DA, K, EM ...) is (+0.084).
- **LLM as world knowledge** for prefix -> class per board: blind fresh agent +0.028 (APr 0.616 -> 0.668), dev3 neutral. A detector
  vote per board (board_prior.py) did not pass dev3 (detector worst exactly on the rare classes).
- **Class head works only with appearance in the part token**: no detector scores -> head 0.559; with detector 9-class scores 0.694;
  with 30 % score dropout (stops copying the simulated, too-accurate detector) 0.701 head / 0.724 mix, clean41 link 93.7 %, class
  head 93.7 % (both best so far). Footprint-type class target alone: no clear gain.
- Negative: 200k steps overfit (class loss 0.037, val class acc falls) -> 100k stays; distance-rank pair features and a test-time
  board offset prior give nothing; DDP on 2 GPUs gives no speed-up (step time is fixed overhead).
- 98 % link target: 12 % of labels are "messy" (printed nearer another part), 75 % acc on them = 47 % of the errors; errors bunch on a
  few boards (DigitalDiscovery 54 / 191).
- Error attribution (clean41, noise 1.0): 319 wrong classes = link 126, OCR 77, naming 44, no label 72.
